# Nikhil Shrestha - Resume Website

A single-page HTML resume built with semantic HTML tags, focusing on clarity, structure, and readability. No CSS or JavaScript used—just pure HTML for maximum compatibility and simplicity.

1. Clone or download this repository.
2. Open `index.html` in any web browser.

## Usage

- Browse the resume sections: About, Skills, Experience, Projects, Education, and Contact.
- No dependencies or build steps required.
